# 🚀 Joseph Herrera - Landing Page Profesional

Una landing page moderna y elegante diseñada para mostrar servicios tecnológicos y soluciones digitales. Creada con HTML, CSS y JavaScript vanilla con animaciones suaves y diseño totalmente responsive.

## ✨ Características

- **🎨 Diseño Moderno**: Interfaz limpia y profesional con gradientes y sombras suaves
- **📱 Totalmente Responsive**: Adaptable a todos los dispositivos y tamaños de pantalla
- **⚡ Animaciones Elegantes**: Efectos de scroll, hover y transiciones suaves
- **🎯 Secciones Modulares**: Estructura organizada y fácil de personalizar
- **📧 Sistema de Contacto**: Integración con WhatsApp y Email
- **🌙 Soporte Dark Mode**: Se adapta al tema del sistema operativo
- **♿ Accesible**: Diseñado siguiendo buenas prácticas de accesibilidad
- **🔧 Optimizado**: Código limpio y bien comentado

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica y moderna
- **CSS3**: Flexbox, Grid, Animaciones y Variables CSS
- **JavaScript ES6**: Funcionalidades interactivas y animaciones
- **Font Awesome**: Iconos profesionales
- **Google Fonts**: Tipografía moderna (Inter)

## 📋 Secciones Incluidas

1. **Hero Section**: Presentación impactante con CTA
2. **Sobre Mí**: Información personal y habilidades
3. **Servicios**: Catálogo de soluciones ofrecidas
4. **Portafolio**: Proyectos destacados
5. **Contacto**: Formulario y enlaces directos
6. **Footer**: Información de copyright y enlaces

## 🚀 Cómo Usar

### Opción 1: Abrir directamente
1. Simplemente abre el archivo `index.html` en tu navegador

### Opción 2: Servidor local
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# O usar servidor estático
npm start
```

### Opción 3: Servidor con Python
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

## 🎨 Personalización

### Colores
Edita las variables CSS en `styles/main.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --accent-color: #f59e0b;
    /* ... más variables */
}
```

### Contenido
- **Textos**: Edita directamente el HTML en `index.html`
- **Servicios**: Modifica la sección de servicios en el HTML
- **Portafolio**: Actualiza los proyectos en la sección correspondiente

### Contacto
- **WhatsApp**: Cambia el número en `js/main.js` línea 45
- **Email**: Actualiza el correo en `js/main.js` línea 48

## 📱 Responsive Breakpoints

- **Desktop**: 1025px y superior
- **Tablet**: 769px - 1024px
- **Mobile**: 481px - 768px
- **Small Mobile**: 320px - 480px

## 🎯 Optimización de Rendimiento

- **Lazy Loading**: Imágenes cargan cuando son visibles
- **Animaciones GPU**: Usan transformaciones 3D para mejor rendimiento
- **Código Modular**: CSS y JavaScript separados y organizados
- **Sin Dependencias Pesadas**: Sin frameworks pesados, vanilla JS
